# Wimbledon Champions Analysis (Tableau)

Team coursework project for a Data Visualization Tools and Techniques course (November 2021). It uses Tableau to explore Wimbledon singles finals from 1877 to 2016: who won, who they beat, and how nationalities and seedings changed over time.

## Contents

| File | Purpose |
|---|---|
| `wimbledons_champions.csv` | Dataset of men's and women's finals: champion, runner-up, nationalities, seeds, score and year |
| `E0420018-Project Report.docx` | Project report with the problem statement, questions, dashboards and conclusions |

The Tableau workbook itself is not included; the dashboards are shown in the report.
